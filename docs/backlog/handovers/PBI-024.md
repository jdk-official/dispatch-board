### Outcome summary

When the board exporter keeps a project tab from an earlier export because its source went missing (FR-153), it now stamps `carriedSince`, the time the carry began.
- The value holds while the tab stays carried, and the kept file stays byte-identical run to run, so `refresh.py` pushes the tab once and then plans no write for it.
- When the source comes back, the next export rebuilds the tab without the marker.
- A corrupt kept file no longer stops the whole export.
- `CLAUDE.md` documents the field.
- The page's warning that reads it (FR-191 / AC-126) shipped in PBI-002.

**Unblocks:** PBI-004 (shared derivation module), which had waited because both change `exporters/export_board.py`.
