### Outcome summary

The collector is the first half of the local-first app.
- It reads each transcript from where it stopped, so an appended line costs only that line's bytes (AC-63), and it recovers from truncation or replacement.
- It derives session, run, project, catalogue and last-refresh records through the shared `derive` module, equal to the session exporter's documents (AC-64), whether read in one pass, in pieces, or across a restart.
- `local/db.py` opens the database in WAL mode, checks an existing file read-only before touching it, refuses network paths (AC-115) and foreign or non-database files, and signals changes for the future server.
- The mass-delete guard is decided before any write (AC-119); unlinked sessions are pruned by age (AC-120, AC-121), and a pruned session keeps its reading position while its file is in the window.
- A failed read counts nothing twice, and a malformed stored state resets just that session.

**Unblocks:** PBI-005 (local server), PBI-006 (page data adapter) and PBI-025 (local tab and status records).
