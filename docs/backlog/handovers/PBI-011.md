## What landed

A review findings ledger: what each review round found, what has since been fixed, and how many rounds a work item took.

- **`exporters/derive.py`** — derives a round's findings from its result (id, severity, title, `file:line`, remediation) and builds the per-project document: per work item, the open findings, the resolved findings, the rounds so far and the rounds to GO. A finding listed in one round and absent from the next is resolved; one still listed is open (AC-77). Each finding carries the round it was first and last seen.
- **`exporters/export_sessions.py`** — writes `projectTabs/<projectId>.findings` for any project with a finished round, and deletes its own document when there is none. It reuses the existing `projectTabs` collection, so no new collection and no change to the mass-delete guard.
- **`exporters/export_board.py`** — its wipe of that folder now touches only its own five tabs, so the two exporters no longer depend on run order.
- **`site/index.html`** — the findings ledger view: open in amber, resolved in green, with the round each finding was first and last seen.
