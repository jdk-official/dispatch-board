### Outcome summary

The dispatch board now has an Agent catalogue tab after Dispatch.
- **What it shows:** every agent and skill in the agent-catalog marketplace (30 and 21, in 8 plugins), grouped by plugin. Each entry has its full description, use count, last use, the projects that used it, and "never used" otherwise.
- **Tiles:** "N of M agents used" and "N of M skills used" for the current view beside the all-sessions figure, plus a panel for types outside the catalogue.
- **Exporters:**
  - `export_catalogue.py` (new) writes `catalogue/index`;
  - `export_sessions.py` now records each run's agent type and each session's skill use;
  - `refresh.py` manages and guards the new collection.
- **Page:** each tab renders in isolation, so one failing tab cannot blank the others. The page test fails on any unexpected `console.error`.
- **Live:** shipped to the live board on 2026-09-11, with 102 store writes, no deletes, and the page republished to the same URL.
